## คำถามท้ายบท

**Q1 - เครื่องมือ:**
ขณะรันคำสั่ง `flutter run` ครั้งแรกพบปัญหา Gradle build failed เนื่องจากหา Android NDK เวอร์ชัน `28.2.13676358` ไม่พบ จึงแก้ไขโดยเปิดหน้าต่าง SDK Manager ในโปรแกรม Android Studio เพื่อโหลดเวอร์ชั่นใหม่ที่ระบบต้องการคือ `28.2.13676358`

**Q2 - Reload:**
เมื่อ Likes เป็น 3 อยู่ การกด `r` (Hot Reload) จะยังคงค่า Likes ไว้ที่ 3 เหมือนเดิม เพราะ Hot Reload จะเรียกเมธอด `build()` ใหม่โดยยังคงรักษา State ปัจจุบันของแอปไว้ แต่การกด `R` (Hot Restart) จะรีเซ็ตค่า Likes กลับเป็น 0 เพราะ Hot Restart เป็นการเริ่มรันแอปใหม่ตั้งแต่ฟังก์ชัน `main()` ทำให้ State ทั้งหมดถูกสร้างขึ้นใหม่

**Q3 - โค้ด และ Git:**
- การอัปเดตตัวแปร `_likes++` ต้องทำภายใน `setState()` เพื่อแจ้งให้ Flutter Framework รู้ว่าสถานะภายใน (State) ของ Widget มีการเปลี่ยนแปลง และสั่งให้เรียกเมธอด `build()` ใหม่เพื่อ UI อัปเดตตัวเลขให้ตรงกับค่าล่าสุด
- **ตัวอย่าง Commit:** `Add like counter with setState` เป็นการเปลี่ยนคลาส `HomePage` จาก `StatelessWidget` เป็น `StatefulWidget` เพิ่มตัวแปร `_likes` ฟังก์ชัน `_like()` และเพิ่ม `FilledButton` สำหรับกดเพิ่มยอดไลก์
